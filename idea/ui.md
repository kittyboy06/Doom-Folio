# DOCTOR DOOM — 3D DEVELOPER PORTFOLIO UI/UX

Design a premium, cinematic, interactive 3D developer portfolio for **Afsal Ahmed Khan A**.

This is a DESIGN-FIRST task.

Your responsibility is to create the complete visual system, UI/UX, layout, responsive behavior, interaction design, animations, and component structure.

Do NOT focus on backend architecture or complex Three.js implementation. The resulting UI must, however, be structured cleanly so another developer can wire the real 3D scene and data later.

---

# 1. CREATIVE DIRECTION

The entire portfolio is inspired by **Doctor Doom / Victor Von Doom**, but it must NOT look like a generic Marvel fan website.

The experience should feel like:

> "A developer's portfolio hidden inside Doctor Doom's private Latverian technological archive."

Visual references:

* Doctor Doom
* Latverian technology
* futuristic laboratory
* medieval sovereignty
* gunmetal armor
* emerald energy
* brass machinery
* holographic HUDs
* classified government archives
* volumetric smoke
* advanced AI systems
* cinematic sci-fi interfaces

The design should feel premium, mysterious, intimidating, technical and sophisticated.

Avoid childish comic-book styling.

---

# 2. DO NOT DO THESE

Do NOT create:

* generic developer portfolio layouts
* standard SaaS dashboards
* Marvel red/blue superhero colors
* excessive Marvel logos
* cartoon graphics
* generic cyberpunk neon
* excessive glassmorphism
* excessive glowing text
* random floating shapes
* unnecessary gradients everywhere
* huge amounts of text
* cookie-cutter card grids

Doctor Doom should be the inspiration for the WORLD and ATMOSPHERE, not a collection of Marvel logos.
